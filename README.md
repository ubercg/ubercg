## Proyectos propios

Diseño y desarrollo proyectos que conectan arquitectura, aplicaciones web e inteligencia artificial.

### [BLOQUE Hub](https://github.com/ubercg/bloque-hub)

Plataforma para la gestión de espacios, reservas y operación interna. Combina Next.js y React con FastAPI, PostgreSQL y procesamiento asíncrono mediante Celery y Redis.

### [TaskflowAI](https://github.com/ubercg/taskflowai)

Aplicación de gestión de proyectos y tareas con React, FastAPI y PostgreSQL. Incluye pruebas automatizadas y configuración de integración continua para backend y frontend.

### [Agent Office](https://github.com/ubercg/agent-office)

Proyecto de orquestación multiagente con enfoque local-first, basado en LangGraph, FastAPI y Ollama.
